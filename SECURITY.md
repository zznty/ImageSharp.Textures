# Security Policy

## Supported Versions

Security fixes are provided for the latest release on `main`.

| Version | Supported |
|---|---|
| Latest (`main`) | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please report suspected security vulnerabilities (such as out-of-bounds reads or unbounded allocations on malformed DDS/KTX/KTX2 inputs) via GitHub Private Vulnerability Reporting on this repository rather than in a public issue.

Include:
- Affected version or commit SHA
- Target framework, runtime, and OS
- Minimal reproduction or malformed input sample
- Expected vs. actual behavior
